# Lesson 06: Email Evaluation Methods

Run `course.py 06`. Use deterministic checks for tool order, campaign ids,
format, addresses, links, numbers, and relationship red lines. Use LLM judges
for tone, relevance, clarity, and broader claim support. Use human review for
judge disagreements and new failure classes.

The agent cannot send mail. A drafts-only boundary is easier to prove when no
send tool exists.
