# Lesson 03: Email Agent Tool Routing

Run `course.py 03 --provider both`. One provider-neutral router uses OpenAI or
Anthropic adapters without changing the three typed tools. A correct path loads
the named synthetic brief, drafts from that brief, and checks the exact draft.

Inspect the transcript, tool arguments, and AIEDS rows. A polished email is not
enough if the campaign id changed or the checker saw different text.
