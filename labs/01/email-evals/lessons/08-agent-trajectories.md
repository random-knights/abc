# Lesson 08: Email Agent Trajectories

Run `course.py 08 --provider both`. Equivalent draft requests should converge on
the same three-tool path. Path length counts the user step, router turns, and
tool calls. Pair efficiency with correctness because a short wrong path is still
wrong.

AIEDS makes model count, tokens, latency, energy, carbon, and tree-time visible
for each trajectory.
