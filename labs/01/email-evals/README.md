# Email Evals Course

This self-contained course mirrors `labs/00/agent-evals` for a draft-only email
campaign agent. It keeps the same dual-provider seam, Phoenix span tracing,
append-only AIEDS records, deterministic evaluators, LLM judges, experiments,
judge calibration, and production-style release gate.

The runnable mailer that informed the exercise is private and includes sender
context that does not belong in a public course. This lab therefore uses only
the architecture and safety boundaries. Its campaign data is generated by
`scripts/make_fixture.py` and labeled `synthetic_labeled` in both source and
output. No organization, person, relationship, contact, address, or status is
real. The agent drafts. It has no send tool.

## Install

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\make_fixture.py
```

Set `OPENAI_API_KEY` and `ANTHROPIC_API_KEY` in the process environment. Do not
put either value in this folder.

## Start Phoenix

```powershell
.\.venv\Scripts\python.exe -m phoenix.server.main serve
```

Phoenix serves its UI on `http://127.0.0.1:6006`. The course exports OTLP spans
to `http://127.0.0.1:6006/v1/traces` under project `email-evals-course`.

## Run

```powershell
.\.venv\Scripts\python.exe course.py all --provider both
.\.venv\Scripts\python.exe scripts\dump_phoenix_spans.py
```

Use `--full` to run every included campaign case. Generated transcripts,
experiment summaries, and AIEDS rows stay in ignored `outputs\` and `traces\`
folders. The checked summary belongs in `evidence\verified-runs.md`.

## What The Agent Does

For each named synthetic campaign, the router must:

1. Load the exact campaign brief.
2. Draft an email from that brief.
3. Run deterministic format, grounding, privacy, and drafts-only checks.
4. Return the checked draft without sending anything.

The evaluator set checks tool order, campaign id fidelity, required email
format, relationship red lines, unsupported numbers and links, privacy, clear
calls to action, tone, and claim support. LLM judges never replace the hard
safety rules.

## Source Boundary

The public fixture is synthetic because the canonical work mailer is private
and its fixed sender facts are internal. Copying those facts into a public lab
would break the public boundary. The course does not use its recipient data,
member seam, organization names, campaign drafts, or relationships.
